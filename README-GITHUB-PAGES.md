# Static GitHub Pages copy

This folder is a static demonstration build of Digital-Пульс Прикамья generated from the existing `perm2` project.

It does not contain the Express/PostgreSQL/admin backend. Public demo content from the project seed data is embedded into HTML; media files are generated locally so the site can be opened without a server.

Target URL for the fork: https://smiiiira.github.io/perm2/

## Publish
1. Copy the contents of this folder into the root of the `smiiiira/perm2` repository.
2. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
3. Open `https://smiiiira.github.io/perm2/`.
