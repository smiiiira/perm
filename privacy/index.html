Политика конфиденциальности

Обновлено: 21.09.2026

1. Общие положения

Настоящая политика описывает порядок обработки персональных данных на сайте «Digital-Пульс Прикамья». Сайт не предусматривает регистрацию пользователей и не собирает персональные данные посетителей.

2. Какие данные обрабатываются

Персональные данные пользователей (посетителей) не собираются и не обрабатываются. Учётные записи существуют только у администраторов сайта.

3. Cookie-файлы

Сайт использует cookie-файлы, необходимые для работы (в том числе для возобновления позиции прослушивания аудиогидов и сессий администраторов). Продолжая использовать сайт, вы соглашаетесь с использованием cookie-файлов.

4. Аналитика

На сайте используется система веб-аналитики Яндекс.Метрика для сбора обезличенной статистики посещений. Данные передаются ООО «ЯНДЕКС» в соответствии с их политикой конфиденциальности.

5. Контакты
